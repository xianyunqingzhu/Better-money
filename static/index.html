快速上手

  1. 设置页填好「初始余额」「月预算」「API Key」（AI 用哪家填哪家）
  2. 每晚把当天花销一口气打进智能记账框（支持多笔、AA、补记）
  3. 购物小票或支付截图用「上传截图 / 小票」；月底漏记用「导入账单 CSV」
  4. 想买的东西加进目标清单，冷静期帮你拦住冲动消费；收入自动存 30% 进第一目标
  5. 周末点「生成本周总结」，月末点「生成本月总结」
  6. 数据全在 data/ 文件夹：数据库、截图原件、备份都在里面，整个文件夹拷走即可迁移

Key 只保存在本地 data/config.json，不会上传到任何别的地方。

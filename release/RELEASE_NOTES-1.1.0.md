# Better-money 1.1.0 发布说明

## 新增：手机端 Android 版（APK）

- **独立本地账本**：Android 8.0+（API 26+），不依赖电脑、不需要云端服务器。
- **两页主界面**：左滑右滑切换「概览与记账」/「分析与历史」。
  - 首页：当前余额、本月支出、本月收入、月预算、今日可花五项数据；
    预算使用超 80% 黄色提醒、超 100% 红色告警；「记一笔」与手动记账表单、
    拍照识别小票 / 相册多选。
  - 分析页：分类占比环形图、近 30 天趋势、近 8 周对比、目标进度小卡片、
    历史卡片列表（月份/类型/分类/关键词筛选、编辑、删除确认）；
    顶部固定「目标清单 / 总结 / 设置」三个入口。
- **AI 记账**：文字多笔解析（AA、收入、退款、补记日期、估算）与
  小票/截图识别沿用电脑端规则；解析结果逐条确认后才入账；
  识别失败保留原图并可转手动记账。默认 DeepSeek
  （文本 `deepseek-v4-pro`、视觉 `deepseek-v4-flash-vision-exp`），
  API Key 只保存在手机本地。
- **目标与总结**：冷静期、进行中、暂停、达成、放弃、收入自动存、调拨、
  「我买了」「先不买」全部保留；周/月总结支持快捷区间与自定义区间，
  账目变化后标记「建议重新生成」。
- **完整备份**：手机可导出/恢复完整备份 ZIP（默认不含图片），换机可迁移。

## 新增：两端共享同步（电脑端 + 手机端）

- 通过手动传递 ZIP 共享包交换账本：导出 → 微信/网盘/USB 传文件 → 导入预览 → 合并。
- 合并规则：同一天两边都有新变化才产生冲突（按天三种处理：保留本机 /
  使用包内 / 合并逐条）；单侧修改自动采用；目标按 UUID 逐条处理；
  删除通过删除标记传播，已删除记录不会复活；重复导入同一包幂等。
- 共享包不含 API Key、总结正文、图片原件、日志与运行状态；
  金额固定两位小数；导入全程事务，失败自动回滚。
- 电脑端「设置 → 数据与共享」区块；手机端「设置 → 数据与共享」。

## 数据层升级（schema v3）

- 交易、目标、单品明细、省下的钱全部获得全局唯一 UUID；
  本机设备标识、软删除与最后同步时间戳；新增同步元数据表。
- 升级自动完成：启动时先做迁移前备份，旧数据自动回填 UUID；
  物理删除只在删除标记同步确认后进行。
- 完整备份格式不变，仍然剔除 API Key 并带校验。

## 下载与校验

- APK 见本 Release 的 `better-money-app-1.1.0.apk`；
  安装前请用附件中的 SHA-256 校验值核对文件。
- 电脑端安装包：`BetterMoney-Setup-1.1.0.exe`（覆盖安装即可，数据不受影响）。

## 升级注意

- 手机覆盖安装新 APK 不清除数据；电脑端覆盖安装同理。
- 首次在手机使用：可用「设置 → 数据与共享 → 导入共享包」导入电脑导出的基准包。

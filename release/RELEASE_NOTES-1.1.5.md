# Better-money v1.1.5 / v1.1.4 · 手机端更新说明

> 仅手机端更新；电脑端保持 1.1.1 不变。应用 ID 与签名不变，可直接覆盖安装。

## v1.1.5 修复

- **提示「已入账」但历史与图表不更新（根因已定位）**：不是数据库容量上限。
  智能解析／小票的保存逻辑会把「同一天 + 同商家 + 同金额」的支出当作重复而跳过，
  界面却仍按提交笔数提示「已入账」，记录其实没有入库，历史和图表自然不更新。
  现在这类真实的重复消费会**分别保存**，提示也按**实际保存笔数**显示；
  保存过程中按钮禁用，避免连点重复提交。
- **历史筛选漏记录（另一处独立问题）**：历史过去先取最近 1000 笔再按月份/类型/
  分类/关键词筛选，较早月份可能被漏掉；现在直接按条件查询，每次 100 笔可继续加载，
  不再有 1000 笔总上限。从主入口进入会清空旧筛选，从分类图表进入则保留所点分类。

## v1.1.4 优化

- 首页待办换成暖琥珀色卡片、深色文字与数量标记，深色模式配套配色。
- 首页新增待办管理捷径；底部「记账与待办 / 分析与历史」切换，仍支持横向滑动。
- 未完成待办与已完成历史都支持删除（删除前确认，并提示无法从历史恢复）。
- 首页勾选完成后提供 8 秒「撤销」入口。
- 编辑待办返回时保护未保存内容；保存中有状态提示并防重复提交。
- 提升文字对比度、字号层级、卡片层次与按钮触控区域，支持「减少动态效果」。
- 修复抽屉关闭后立刻重开被旧计时器隐藏的问题；提示消息不再堆叠。

# Better Money 1.0.0 发布说明（Windows）

## 安装

1. 下载 `BetterMoney-Setup-1.0.0.exe`（SHA-256 见 `SHA256SUMS.txt`）。
2. 双击安装：默认装到 `Program Files\Better Money`，需要一次管理员授权。
3. 装完从桌面/开始菜单双击 Better-money 即可：**服务健康检查通过后才会打开浏览器**，
   不会出现第一次点了打不开的情况；再点一次只是回到同一个实例。

应用无需 Python、无需联网装依赖；个人数据保存在 `%LOCALAPPDATA%\BetterMoney`。
升级：直接装新版安装器，数据保留。卸载：默认保留数据；勾选「同时删除我的
账单、设置、图片和备份」并二次确认才会删除。

## 本版内容

- 四步首次引导：全新开始 / 迁移旧数据 / 从备份恢复 → 初始余额 → 预算 → AI（可跳过）
- 多目标看板：所有活跃目标按优先级显示「已存 / 需要 / 还差」，自动存按优先级跨目标分配
- 目标删除（确认后仅移除规划金额，不影响账本余额）
- 总结：选区间（本周/上周/本月/上月/自定义）生成周总结或月总结；同区间覆盖重写；可删除
- 账本：一次性起始日初始余额、每月自动滚动；对账调整可撤销
- 设置：AI 服务商预设（OpenAI/DeepSeek/Qwen/自定义）+ 一键测试连接；
  受保护的初始余额更正；立即备份 / 恢复备份 / 导出完整备份 ZIP / 打开数据文件夹
- 上传校验：图片只收 PNG/JPG/WebP（10 MiB/张、每次最多 10 张）；账单 CSV/XLSX/XLSM（20 MiB）
- 单实例启动器：端口被占用自动换端口；设置页可退出服务

## 已知说明

- 安装包未做代码签名：首次运行如出现 SmartScreen「Windows 已保护你的电脑」，
  点「更多信息 → 仍要运行」。
- 暂无自动更新 / 托盘 / 云同步；数据永远在本机。

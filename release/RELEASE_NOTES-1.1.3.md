# Better-money v1.1.3 / v1.1.2 · 手机端更新说明

> 仅手机端更新；电脑端保持 1.1.1 不变。

## v1.1.3 新增

- **待办清单**（首页顶部）：支持勾选完成，随手记随手清。
- **待办管理**（第二页）：新建、编辑、上下排序、历史记录与恢复。
- **界面简化**：移除首页「月预算 / 今日可花」与设置里的月预算入口；
  智能解析按钮变大、手动记账按钮变小（位置不变）。

## v1.1.2 新增

- **退款自动配对**：记退款时自动匹配历史支出（商家一致 + 金额对得上 + 60 天内），
  全额退自动移除原支出、部分退自动扣减金额；找不到时可在确认面板
  「从历史选择」手动挑，也可「不配对」按独立退款记账。
- **相册多选与追加**：支持多选，预览页可「＋ 添加照片」反复追加至 10 张，
  缩略图可单独移除。
- **目标自动存优化**：「已暂停」目标也参与自动存；修复同日同金额同商家退款被查重误跳。
- **界面清理**：移除首页「待同步」角标；首次使用提示只出现一次。

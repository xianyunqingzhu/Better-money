# Better-money 1.1.1 发布说明

## 修复（手机端）

- **余额显示错误**：首页「当前余额」被错误地按 1/100 显示（如 558.74 元显示为 5.59）；
  「今日可花」也存在同样单位问题。已修复并新增回归测试（与电脑端 /api/summary
  逐项对齐交叉验证）。
- **周对比空白**：周日时「近 8 周」窗口整体前移一周，导致本周数据落在窗口外、图表
  没有内容。已修复并新增周日回归测试。
- **初始余额被共享包导入**：现在「应用包内设置」只导入月预算、自动存比例与冷静期
  天数；初始余额与起始日期**永远不会自动导入**。手机首次导入且尚未设置起始日期时，
  导入完成后会单独询问是否采用包内参考值，确认后才写入。电脑端同步此规则。
- **AI 测试连接失败排查增强**：兼容服务不支持 json_object 时自动去掉重试（与电脑端
  行为一致）；错误信息展示 HTTP 状态与详细原因；设置页提示 Key 需与 Base/模型
  属于同一服务商。
- **记账入口改版**：首页直接内联「智能解析」输入框（无需点按钮即可用）；
  「手动记账」改为独立按钮打开表单；删除重复的手动记账区块与输入法提示语。
- **历史记录独立入口**：页面二顶部新增「历史记录」按钮（与总结一致），点进去
  才是完整列表；分类占比点击分类时直接打开历史页并按该分类筛选。
- **debug 包安装失败**：debug APK 现在与正式版使用同一签名，可直接覆盖安装，
  无需卸载（卸载会清空数据）。

## 升级

- 手机：直接覆盖安装新 APK（1.1.1，签名不变，数据保留）。
- 电脑：运行新版安装包覆盖安装（数据保留）。
- 已受影响的数据无需重导：升级后到「设置 → 账本」核对初始余额与起始日期即可；
  余额会自动恢复正确显示。

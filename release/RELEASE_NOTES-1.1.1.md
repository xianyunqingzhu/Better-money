# Better-money v1.1.1

> 一句话：新增**手机端 Android 应用**，支持**电脑与手机通过共享包交换账本**；并修复了手机端若干问题。

## 新增功能

### 📱 手机端 Android 应用（全新）

- **独立本地账本**：Android 8.0 及以上，不依赖电脑、不需要云端服务器，断网也能查账和手动记账。
- **两页横滑界面**：
  - 首页：当前余额 / 本月支出 / 本月收入 / 月预算 / 今日可花五项数据、预算使用提醒（超 80% 黄、超 100% 红）、**智能解析**（直接输入文字即可用）、拍照识别小票 / 相册多选。
  - 第二页：分类占比环形图、近 30 天支出趋势、近 8 周对比、目标进度小卡片；顶部「目标清单 / 总结 / 历史记录 / 设置」四个入口。
- **AI 记账与电脑端同规则**：文字多笔解析（AA 分摊、退款、昨天/前天补记、估算金额、取现/转账/还款）、小票截图识别；解析结果**逐条确认后**才入账，失败不丢数据；断网时手动记账兜底。
- **目标清单全功能**：冷静期、收入自动存、目标间调拨、暂停/恢复、「我买了」「先不买」、省下的钱统计。
- **周/月总结**：本周 / 上周 / 本月 / 上月 / 自定义区间；账目变化后提示「建议重新生成」。
- **历史记录**独立页面：按月、类型、分类、关键词筛选；编辑、删除（删除会同步传播）。
- **本地完整备份/恢复**：换机可迁移，可选是否包含图片；**API Key 只保存在手机本地**，绝不进入共享包或备份包。

### 🔄 电脑 ↔ 手机共享同步（全新）

- 通过手动传递 ZIP 共享包交换数据：微信文件传输、USB、网盘皆可，**不需要两台设备同时在线、不需要同一网络、不需要云端**。
- 电脑端「设置 → 数据与共享」、手机端「设置 → 数据与共享」均可导出/导入。
- 导入先预览：显示来自哪台设备、新增/修改/删除笔数；**同一天两边都改过**才出现冲突面板，支持「保留本机这一天 / 使用包内这一天 / 合并两边逐条处理」；目标冲突逐条选择；疑似重复提示（默认保留两笔）。
- 删除会传播到另一台设备，已删除记录不会「复活」；重复导入同一个包不会产生重复；任一失败自动回滚。
- 共享包**不含** API Key、总结正文、图片原件、日志；「应用包内设置」只导入月预算、自动存比例、冷静期天数，**初始余额与起始日期永不自动导入**（手机首次导入时单独询问是否采用参考值）。

### 🗄 数据层升级（schema v3）

- 交易、目标、单品明细、省下的钱全部获得全局唯一标识（UUID）、软删除与同步时间戳。
- 升级自动完成：启动时先自动创建迁移前备份，旧数据自动补全标识，全程无需手动操作。
- 备份安全增强：zip 炸弹检测收紧；兼容新版 Python。

1. 首页余额显示错误（被按 1/100 显示）与「今日可花」单位错误。
2. 周日时「近 8 周」对比图空白。
3. 初始余额 / 起始日期不再随共享包自动导入。
4. AI 测试连接：兼容服务商自动重试，并显示详细失败原因。
5. 首页改版：智能解析输入框直接可用，手动记账改为独立按钮（不再重复展示）。
6. 历史记录改为独立入口页（第二页顶部新增按钮）。
7. debug 安装包与正式包同签名，可直接覆盖安装。

## 安装与升级

### 电脑（Windows 10/11 64 位）

下载 `BetterMoney-Setup-1.1.1.exe`，双击安装即可（覆盖安装，账单数据不受影响；安装器会自动关闭正在运行的应用）。

### 手机（Android 8.0 及以上）

1. 下载 `better-money-app-1.1.1.apk`，用任意方式传到手机。
2. 首次安装需允许「安装未知来源应用」；覆盖安装数据保留、无需卸载。

### 首次把电脑账本搬到手机

1. 电脑：设置 → 数据与共享 → **导出共享包（发到手机）**。
2. 把 ZIP 传到手机：设置 → 数据与共享 → **导入共享包（来自电脑）**，按预览确认。
3. 手机：设置 → AI 填入 API Key 并「测试连接」（**Key 属于哪家服务商，Base 和模型就填哪家**）。
4. 导入完成后按提示确认是否采用电脑端的初始余额参考值。

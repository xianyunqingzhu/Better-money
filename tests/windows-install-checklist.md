# Windows 安装版验收清单（Gate C 证据）

在**无 Python** 的干净 Windows 10 64 位与 Windows 11 64 位各执行一遍，
每项完成后勾选，记录结果。

- [ ] 默认路径安装完成（`Program Files\Better Money`）
- [ ] D 盘中文+空格路径安装完成（如 `D:\我的软件\Better Money`）
- [ ] 双击桌面快捷方式：**第一次点击**即在服务健康检查通过后打开浏览器
- [ ] 快速连点 5 次快捷方式：始终只有一个服务进程（`runtime\instance.json` 的 PID 不变）
- [ ] 8642 端口被其他 HTTP 服务占用：应用自动换端口并正常打开
- [ ] 断网 + API Key 留空：手动记账、目标、看板、对账、备份全部可用
- [ ] 旧源码版数据迁移：首次引导「迁移旧数据」显示笔数并可导入
- [ ] 从旧安装版升级覆盖安装：账单数据完整保留
- [ ] 卸载（不勾选删除数据）：`%LOCALAPPDATA%\BetterMoney` 保留
- [ ] 重装后自动发现并继续使用保留的数据
- [ ] 卸载勾选删除数据 + 二次确认：仅删除 `%LOCALAPPDATA%\BetterMoney`
- [ ] Windows 显示缩放 100% / 125% / 150%：目标金额、还差金额清晰可读

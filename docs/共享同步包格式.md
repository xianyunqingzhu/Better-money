# 共享同步包格式说明（format: better-money-share v1）

手机端与电脑端通过本格式的 ZIP 包交换账本数据。**共享包不是整库备份**，导入时按
UUID 合并；重复导入同一个包不会产生重复记录。

## 包内文件

```
better-money-share-<device>-<yyyyMMdd-HHmmss>.zip
├── manifest.json         包元数据
├── transactions.json     全部未删除交易
├── line_items.json       单品明细（按 transaction_uuid 关联）
├── goals.json            全部未删除目标
├── savings_wins.json     全部未删除「省下的钱」记录
├── settings_public.json  公开账本设置（不含 API Key 等敏感项）
└── tombstones.json       删除标记
```

包内 **不含**：API Key、API Base、模型名、总结正文/配图、图片原件、日志、运行端口、
token。记录不暴露本机整数主键（id），只使用 uuid。

## 字段约定

- `uuid`：32 位十六进制，全局唯一，生成后永不复用。
- 金额（amount/price/saved/qty）：十进制字符串，固定两位小数（如 `"29.90"`）。
- 时间（created_at/updated_at/deleted_at）：`YYYY-MM-DD HH:MM:SS`（设备本地时间）。
  manifest.created_at 为带时区的 ISO 8601。
- 交易 type：支出 / 收入 / 退款 / 取现 / 转账 / 还款。
- tombstone.kind：transaction / goal / savings_win。
- **refund_of（可选附加字段，v1.1.2 起）**：退款记录指向被修正的原支出 uuid；
  为空表示独立退款。旧版电脑端读取时忽略该字段，不影响导入；
  手机端（v4 本地库）会据此在统计中排除已配对的退款。

## manifest.json

```json
{
  "format": "better-money-share",
  "format_version": 1,
  "app_version": "1.1.2",
  "schema_version": 3,
  "device_id": "<32位hex>",
  "device_name": "手机",
  "platform": "desktop | mobile",
  "created_at": "2026-08-22T12:00:00+08:00",
  "date_min": "2026-08-01",
  "date_max": "2026-08-22",
  "counts": {"transactions": 23, "goals": 1, "savings_wins": 0,
             "line_items": 0, "tombstones": 1},
  "includes": {"transactions": true, "goals": true, "savings_wins": true,
               "images": false, "summaries": false, "api_key": false}
}
```

> schema_version 读取端接受 3~4；导出仍写 3（refund_of 为向后兼容的附加字段）。

## 合并规则（两端共用）

- 每条记录带 `last_synced_at`：相对上次同步「两侧都变化」才进入冲突；只有一侧变化
  自动采用变化侧；重复导入幂等。
- 交易冲突按日期分组，提供三种快捷处理：保留本机这一天 / 使用包内这一天 /
  合并两边逐条处理（保留本机 / 采用包内 / 都不保留）。
- 目标冲突按 UUID：两侧修改时默认采用 updated_at 较新的一侧（用户可覆盖）；
  删除与修改同时发生必须人工选择。
- 删除通过软删除 + tombstone 传播；tombstone 已同步后物理清理记录，tombstone 永久
  保留防止复活。
- 相同日期+金额+商家但 uuid 不同 → 只提示「疑似重复」，默认保留两笔。
- 导入全程事务：任一步失败整次回滚。
- 导入成功后按受影响日期把已有总结标记为过期，不自动调用 AI。

### 公开设置的应用规则（重要）

- 包内 `settings_public.json` 始终携带 5 个字段；但「应用包内设置」**只会写入**
  月预算（monthly_budget）、自动存比例（auto_save_ratio）、冷静期天数（cooldown_days）。
- **初始余额（initial_balance）与初始余额日期（initial_balance_date）永远不会
  自动导入**——它们是本机账本口径，包内值仅作参考：手机首次导入且本机尚未设置
  起始日期时，会在导入完成后单独询问是否采用，用户确认后才写入。

## 导入决策 JSON（POST /api/share/apply）

```json
{
  "settings": "keep_local | apply_package",
  "days": {
    "2026-08-19": {
      "mode": "keep_local | keep_peer | merge",
      "items": {"<uuid>": "local | peer | drop"}
    }
  },
  "goals": {"<uuid>": "local | peer | drop"},
  "dupes": {"<uuid>": "drop"}
}
```

## 安全校验（导入前）

拒绝：路径穿越/非白名单成员、符号链接、解压后超过 50 MiB、manifest 格式不符
（整库备份会提示「这不是共享包」）、schema 版本不支持、uuid 缺失/重复、
tombstone 与数据文件冲突、时间/金额/日期字段非法。

# Android 1.1.3

仅修改 `mobile/` 手机产品；电脑端源码和安装目录保持原样。

- 首页最上方新增待办列表，按手动优先级排序，勾选后进入已完成历史。
- 第二页顶部新增「待办事项」入口，支持新建、编辑、上移、下移和历史恢复。
- 新增和恢复的事项放在未完成列表末尾；历史按最近完成时间排序；内容最多 500 字。
- 待办保存在手机本地 SQLite，应用重启后保留，并包含在完整备份中；不通过电脑端共享 ZIP 同步。
- 首页移除月预算、今日可花和预算提醒，设置移除月预算编辑，新生成的总结不再展示预算。
- 智能解析按钮改为宽大按钮，手动记账改为普通大小，位置不变。

## 数据兼容

数据库从 v4 升级到 v5，增加独立 `todos` 表，保留原账本数据。
旧预算字段仅为兼容既有数据及共享包格式保留，不再提供手机端预算操作界面。
完整备份清单记录实际数据库版本。APK 版本码为 4，沿用原应用 ID 与签名。

## 安装后验收

1. 用 1.1.3 APK 覆盖安装，确认旧账本仍在。
2. 第二页新建两项待办，编辑文字并上下移动；返回首页核对顺序。
3. 首页勾选完成一项，退出重开后确认该项仍隐藏。
4. 待办管理进入历史，恢复该项，确认它出现在未完成列表末尾。
5. 确认首页与设置没有预算入口，两个记账按钮位置不变且大小已互换。

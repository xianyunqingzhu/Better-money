# Android 1.1.4

本次仅优化安卓手机端，沿用本地账本和数据库 v5。版本码增加到 5，应用 ID 和签名保持一致。

## 使用体验

- 首页待办采用暖琥珀色背景、深色文字和数量标记，深色模式采用对应配色。
- 首页新增待办管理捷径；底部提供「记账与待办」「分析与历史」切换，仍支持横向滑动。
- 未完成事项和已完成历史均支持删除。删除前确认，并明确提示删除后不能从历史恢复。
- 首页完成待办后提供 8 秒「撤销」入口；恢复操作仍可通过历史记录完成。
- 待办编辑返回时保护未保存内容，保存中展示状态并防止重复操作。
- 改善文字对比度、相对字号、卡片层级及按钮触控区域，支持减少动态效果。
- 修复抽屉关闭后立即重开被旧计时器隐藏的问题；提示消息不再堆叠。

## 验证

- `npm test`：44 项通过，包含未完成/已完成待办删除及重启持久化。
- `npm run build`：TypeScript 与生产构建通过。
- `tests/ui-comfort.cjs`：浏览器触控流程覆盖删除/取消、历史删除、重启、撤销、放弃编辑保护、导航、保存失败恢复、抽屉关闭重开。
- 视口 320/360/412px、100%/150% 字号、深色模式、减少动态效果均通过。
- 独立静态代码复核未发现必须修复项。
- 尚未连接安卓真机测试覆盖安装。

浏览器回归需要先运行 `npm run dev -- --host 127.0.0.1`，在可解析 `playwright` 包且安装了 Edge 的环境中运行 `node tests/ui-comfort.cjs`。可用 `UI_TEST_URL` 指定开发服务器地址；截图写入仓库根目录 `build-output/`。
